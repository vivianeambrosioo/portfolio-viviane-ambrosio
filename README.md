## Publicação e manutenção

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
Atualizações enviadas à branch main são publicadas pelo GitHub Pages. Os arquivos HTML são editáveis e usam somente imagens e fontes locais. Abra index.html para conferir localmente.

Licenças das fontes acompanham os arquivos. Dados fictícios dos cases estão identificados no conteúdo. Não são incluídos briefing, backup ou vídeos de referência.
